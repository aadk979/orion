`@aadharsh/orion-client` builds to a single ES module,
`dist/orion.beta.sdk.js`. It has no runtime dependencies — DOMPurify, the
fingerprinting library, and the WebAuthn helper are bundled in.

```js filename="orion-client.js" copy
import { Orion, getDeviceFingerprint } from './orion.beta.sdk.js';

const orion = new Orion({
    serverUrl: 'https://auth.example.com',
    slug: ''
});

export { orion, getDeviceFingerprint };
```

## The singleton rule

```js
new Orion({ serverUrl });   // ok
new Orion({ serverUrl });   // throws — "The Orion class is a singleton class!"
```

Construct it once, export the instance, import it everywhere. `serverUrl` is
required even when the client and API share an origin. The namespace is forced to
`alpine` internally.

## Initialization

The first call to `onAuthStateChanged` (or any method, which all `await this.initialize()`
first) triggers a one-time bootstrap:

<Steps>
  <Step title="Open the local vault">
    An IndexedDB-backed store for small non-secret values such as the last-used
    email.
  </Step>
  <Step title="Run the captcha check">
    Asks whether this browser already holds a no-auth token; if not, solves the
    challenge and obtains one.
  </Step>
  <Step title="Ask for current auth state">
    Calls the virtual endpoint
    <code>/alpine/api/v1/action/get-current-auth-state</code>.
  </Step>
</Steps>

Four responses are treated as "not signed in" rather than as failures:
`AUTH::MISSING-TOKEN::A::p`, `TOKEN-ACCESS::EXPIRED::A::p`,
`TOKEN-REFRESH::EXPIRED::A::p`, and `AUTH::MISSING-SESSION-CREDENTIALS::A::p`.
Anything else resets the vault and emits `ERROR`.

## Error convention

Expected failures return `{ error: true, errorCode }` rather than throwing. The
one deliberate exception is a flow interruption, which throws an error carrying
`_orionDeviceAuthCompleted` — the sign-in methods catch it and retry.

Client-originated codes are prefixed `CLIENT-`:

| Code | Meaning |
| --- | --- |
| `CLIENT-AUTH-AUTHED-USER-PRESENT` | Called a sign-in method while already authenticated |
| `CLIENT-AUTH-NO-AUTHED-USER-PRESENT` | Called an authenticated method while signed out |
| `CLIENT-MISSING-REVOCATION-TARGET` | `revokeSession` called with neither `tokenId` nor `linkCode` |
| `CLIENT-AMBIGUOUS-REVOCATION-TARGET` | `revokeSession` called with both |
